10:T5e0,# joinPath

join path parts with "/" and without trailing and leading slashes.

### Import
```typescript copy
import { joinPath } from '@fullstacksjs/toolbox';
```

### Signature
```typescript copy
joinPath(array)
```

### Examples
```typescript copy
joinPath(['a', 'b'])                               // 'a/b'
joinPath(['a', '/b'])                              // 'a/b'
joinPath(['a', 'b/'])                              // 'a/b'
joinPath(['a', '/b/'])                             // 'a/b'
joinPath(['a/', 'b'])                              // 'a/b'
joinPath(['a/', '/b'])                             // 'a/b'
joinPath(['a/', 'b/'])                             // 'a/b'
joinPath(['a/', '/b/'])                            // 'a/b'
joinPath(['/a', 'b'])                              // 'a/b'
joinPath(['/a', '/b'])                             // 'a/b'
joinPath(['/a', 'b/'])                             // 'a/b'
joinPath(['/a', '/b/'])                            // 'a/b'
joinPath(['https://a.com', 'b'])                   // 'https://a.com/b'
joinPath(['https://a.com', '/b'])                  // 'https://a.com/b'
joinPath(['https://a.com', 'b/'])                  // 'https://a.com/b'
joinPath(['https://a.com/', '/b/'])                // 'https://a.com/b'
joinPath(['https://a.com/', '?b=a'])               // 'https://a.com/?b=a'
joinPath(['https://a.com/', '/b/', '?query'])      // 'https://a.com/b/?query',
joinPath(['https://a.com/', '?query', '&a=query']) // 'https://a.com/?query/&a=query',
